# Customer concurrency acceptance

**FAIL universal concurrency guarantee; PASS synthetic RPC behavior.** `012` sets `edit_version` to one for preexisting and new rows. A BEFORE UPDATE trigger overwrites attempted version values with `OLD.edit_version+1` and timestamp, checks immutable customer identity/creation metadata; integer overflow errors rather than wraps. The versioned RPC matches tenant, id, non-archived state and expected version and returns SQLSTATE 40001 for stale/unavailable. Authenticated direct UPDATE and version tampering are denied by grants; RPC independently authorizes owner/admin/manager. `tests/database/run-tests.mjs` tests stale, ABA, role, cross-tenant, no-op/privileged updates and simultaneous same-version RPCs (one success, one failure); see `customer version RPC blocks direct writes, stale ABA and cross-tenant/role access` and `customer version RPC allows exactly one simultaneous same-version edit`.

**FAIL:** a privileged direct update does not supply/compare expected version; it can overwrite current state even though it increments version and triggers audit. Owners can disable/alter triggers and overwrite version or history. No full inventory exists of privileged background/import/service writers. Version enforcement is not an invariant against those actors, and direct authenticated writes are intentionally incompatible with old clients. Do not add broad grants. Verify all writers and roles, or design an enforced controlled interface and cutover, before acceptance. Trigger-disable scenarios and actual hosted owner permissions **NOT TESTED**.

**FAIL cross-query financial snapshot:** synthetic `mixed snapshots expose concurrent reconciliation hazard` demonstrates independently read balances and payment histories can straddle a concurrent payment. A single coherent snapshot is not promised by parallel PostgREST requests. Independent fixture checks after concurrent commits are **PASS** for only the constructed ledger; they do not repair the consistency hazard. See `customer-migration-review.md`.
